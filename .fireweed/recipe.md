Go recipe: each module is a Go package, api.go is its interface, evals/ imports that package, and implementation lives under internal/. The embedded standard-library hook converts go test -json to JUnit and checks imports against fireweed modules --json. The initial module path is example.com/project; if you change it, update import paths in .fireweed/canaries/. Keep implementation behind api.go wrappers. Add a setup hook if the project needs dependencies. Run fireweed doctor after committing the setup.
